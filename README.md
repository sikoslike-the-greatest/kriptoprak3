# Практическая работа 5 — Встраивание ЦВЗ в частотную область изображений

Программная реализация **слепого робастного алгоритма встраивания цифровых
водяных знаков (ЦВЗ) на основе межблочной разности коэффициентов ДКП**
(Ko, Huang, Horng & Wang, 2020) для дисциплины «Основы криптографии и
стеганографии».

## Метод

1. Пиксели контейнера переводятся в диапазон `[-128, 127]` (вычитание 128),
   изображение разбивается на блоки `8×8`, к каждому применяется ДКП.
2. Бинарный ЦВЗ перемешивается преобразованием Арнольда; один бит встраивается
   в один блок-носитель.
3. Для каждого блока вычисляется адаптивная сила `S` (по DC-коэффициенту и
   медиане первых 9 AC-коэффициентов).
4. Бит кодируется межблочной разностью `Δ` выбранного среднечастотного
   коэффициента носителя и соседнего (опорного) блока: ось `Δ` разбита на
   регионы шириной `T`, чётные регионы → бит 0, нечётные → бит 1. Коэффициент
   сдвигается шагами `S` до попадания `Δ` в нужный регион с зазором `t`.
5. Обратное ДКП и прибавление 128 дают изображение со встроенным ЦВЗ.

Извлечение **слепое** — исходный контейнер не требуется: бит читается по региону,
в котором находится разность `Δ` (`round(Δ/T) mod 2`).

Граничные блоки (последний столбец/строка) служат опорными, поэтому для
контейнера `N×N` размер ЦВЗ составляет `(N/8−1)×(N/8−1)`.

## Структура

```
dctwm/
  watermark.py     # ядро: блочное ДКП, Арнольд, адаптивная сила, embed/extract
  metrics.py       # PSNR, MSE, RMSE, SSIM, BER, NCC
  cli.py           # CLI: embed / extract (слепое)
  experiments.py   # вычислительные эксперименты -> images/
images/            # рисунки и таблицы (генерируются)
report5.tex        # отчёт (xelatex)
```

## Установка

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Использование

```bash
# встраивание
python -m dctwm embed   --cover cover.png --watermark wm.png \
                        --stego stego.png --params params.json \
                        --T 60 --t 12 --alpha 2 --iters 10

# извлечение (слепое: исходный контейнер не нужен)
python -m dctwm extract --stego stego.png --params params.json \
                        --output recovered.png --watermark wm.png
```

Параметры: `T` — ширина региона разности (запас робастности), `t` — зазор до
границы региона, `alpha` — масштаб адаптивной силы, `iters` — число итераций
Арнольда. По умолчанию `T=60, t=12, alpha=2, iters=10`.

## Эксперименты и отчёт

python -m dctwm.experiments       # генерирует рисунки и таблицы в images/
